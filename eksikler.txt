GÜVENDE PROJESİ CANLIYA GEÇİŞ EKSİKLER LİSTESİ (KALAN EKSİKLER)

[ ] 1. Mobil Uygulama Canlı Ortam API URL Değişikliği (environment.prod.ts)
    - environment.prod.ts dosyasındaki apiUrl yerel IP adresi (192.168.1.136) yerine gerçek canlı HTTPS adresiyle güncellenecek.

[ ] 2. Android Cleartext (HTTP) İzinleri
    - AndroidManifest.xml dosyasındaki android:usesCleartextTraffic="true" kaldırılacak ya da false yapılacak (HTTPS zorunluluğu).

[ ] 3. CORS Wildcard İzni
    - main.ts dosyasındaki app.enableCors() üretici IP/alan adı ile kısıtlanacak.

[ ] 4. Google Play Politika Hazırlıkları
    - [ ] Google Play Console için açıklama videosu hazırlanacak.

[ ] 5. Canlı Ortam Değişkenleri (.env) Güncellemesi
    - JWT_SECRET güçlü bir şifreyle güncellenecek.
    - OneSignal API anahtarları canlı hesap anahtarlarıyla değiştirilecek.
